## 開発環境

<!-- 前提OS・必要ツール・セットアップ手順の要点を書く -->

- 必要ツール: git、bash（Windows は Git Bash）、`jq`（無ければ `node` か `python3`。hooks が JSON パースに使う）
- GitHub 操作: `.mcp.json` の GitHub MCP サーバー（初回は `/mcp` で OAuth 認証）。未接続時は `gh` CLI にフォールバック
